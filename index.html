Expense Tracker API
Built 2026
Java 17Spring Boot 3.3MySQL/H2DockerGitHub ActionsAmazon ECREC2IAM
  • Full CRUD REST API built with Spring Data JPA — category filtering, date-range queries, and a category-wise spending summary endpoint, using DTOs to keep entities unexposed.
  • Multi-stage Dockerfile (Maven build stage + slim JRE runtime), with Spring Actuator's /actuator/health wired into the Docker HEALTHCHECK.
  • Two-job CI/CD pipeline in GitHub Actions: build-and-test on every push/PR as a quality gate, push-to-ECR only after merge to main.
  • Environment-driven Spring profiles — H2 for zero-setup local dev, MySQL with env-injected credentials in production — plus a least-privilege IAM policy scoped to one ECR repo.
  • Unit tests written with Mockito, and a docker-compose stack (API + MySQL) to mirror production locally before deploying.
